Why MEIS

不是改一个字段，而是记清「谁在何时负责这台设备」

许多同类系统里，归属科室、安装地点只是扁平当前值——一改就覆盖，历史运维与成本容易悬空。 MEIS 把归属与位置做成时间区间：维修、保养、计量、PM、配件更换等记录，都能按当时所属科室与位置回溯排查。

同类常见做法

归属科室 / 安装地点 = 当前字段。变更即覆盖，历史运维与费用难以按原科室对账。

科室 A → 直接改成科室 B（过去谁负责？成本归谁？对不上）

MEIS 做法

归属区间 · 位置区间：每段有起止时间。台账关联的运维数据始终可按时间段落到正确科室。

  • 字段齐全台账主数据与业务 Sheet 齐套，证照、档案、维保、运维同机可查。
  • 记录完整维修进程、配件更换、保养 / 巡检 / 计量 / PM 计划与执行挂在同一设备。
  • 归属清晰真变更与纠错分流；历史补录可确认生效，避免静默改关键字段。

Capabilities

常规功能介绍

覆盖采购 → 入库 → 台账 → 使用维护 → 质控合规 → 报废处置 → 效益分析的一体化链路。 以下按业务域列出日常可宣传的核心能力（不含未交付路线图能力）。

资产与档案

一台设备一张完整主数据卡，资料与历史同机留痕
Ledger

设备台账

证照、分类、财务与业务字段齐套；列表/详情中文可读，外键「编码 名称」。

Archive

设备档案与图片

合同、说明书等资料挂机管理；支持高拍仪现场成片入库与预览。

History

归属 / 位置历史

按时间段记录所属科室与安装位置，支撑运维与成本区间排查。

Print

资产卡片与标签

三甲式资产卡片打印；贴纸/标签流水可追溯，支撑盘点与扫码。

Audit

主数据变更记录

关键字段改前改后明文可查，混合来源可辨「生成方式」。

Special

特殊设备登记

生命支持、辐射/特种、应急库、租赁等专项台账入口。

库房与盘点

进出仓主从齐套，移动端扫码协同
Warehouse

入库 / 出库 / 退库 / 退货

单据头明细强制齐套，状态回写台账，避免只存主表丢明细。

Inventory

库存盘点

Web 盘点与 App / 小程序扫码盘点协同，差异可留痕。

Dispose

报废与处置

报废申请到归档可查，处置历史可在台账侧聚合查看。

运维闭环

维修与计划性运维挂在同一台设备的时间线上
Repair

维修全流程

报修 → 处理 → 验收；双层状态、进程段与配件更换完整留痕。

Parts

配件更换

维修换件与非维修换件来源可辨；历史补录可确认后生效。

PM

保养 · 巡检 · 计量 · PM

参数 → 计划 → 执行 → 记录主从分离，边界清晰、结果中文展示。

Contract

维保信息与合同

保修/维保覆盖设备可维护，合同履约与台账档案可对照。

质控 · 调配 · 采购

合规上报、公用设备流转与采购链路单据可追溯
QC

不良事件与风险评估

质控合规上报与查询入口齐套，事件可关联设备。

Loan

调配中心（借还）

公用设备借调申请 / 审批 / 归还 / 收费，状态可视。

Purchase

采购与合同

申请 → 审批 → 计划 → 招标 → 合同 → 验收；合同可带付款计划。
